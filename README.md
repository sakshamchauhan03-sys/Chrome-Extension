# Chrome-Extension

A Chrome Extension that integrates Google's Gemini API to summarize web pages, draft emails, or explain complex text directly within your browser. 

Built with vanilla JavaScript and the Gemini API.



## 🔑 Prerequisites

To use this extension, you will need a **Gemini API Key**. 
1. Go to [Google AI Studio](https://aistudio.google.com/).
2. Sign in with your Google account.
3. Click on **Get API key** and create a new key.
4. Save this key somewhere secure (you will enter it into the extension's settings).
